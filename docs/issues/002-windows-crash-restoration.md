# Windows 显示进程异常退出后的光标恢复

## 问题
`SetSystemCursor` 修改系统共享光标，调用进程退出不会自动还原。仅依赖 GUI 的 finally，无法处理任务管理器强制结束进程。

## 解决方法
所有系统光标修改交由独立的 `win_worker` 进程完成。它持有全部原始光标副本，通过匿名管道接收 begin/scale/end 命令。GUI 退出或被强杀后，管道 EOF 触发 finally，还原原始副本。正常退出时主进程关闭管道并等待恢复完成；恢复副本失败时调用 `SPI_SETCURSORS` 重载用户系统方案。

启动锁保证并发命令共用一个 GUI；GUI 生命周期锁防止重复进程；光标进程锁防止旧 worker 尚未恢复时，新 worker 把放大状态保存为原始状态。

## 验证
`tools/smoke_windows.py` 已验证 13 类标准光标从 32×32 放大到 160×160；GUI 强制退出后全部回到原尺寸，随后可重新启动并正常停止。

## 边界
恢复保护覆盖 GUI 崩溃，不覆盖用户同时强杀整个进程树（包括持有副本的 worker）。若发生该情况，可在 Windows 鼠标设置中重新应用光标方案。
