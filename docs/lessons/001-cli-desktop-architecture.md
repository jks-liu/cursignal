# 命令行触发桌面提示的实现经验

- 分发入口与桌面能力分开设计。uvx 负责安装和启动，桌面行为仍取决于操作系统接口；不能把跨平台 GUI 库等同于跨平台系统控制。
- 短生命周期 CLI 只使用标准库，不导入 Qt。长期显示交给单实例进程，既让命令快速返回，也方便不同任务追加消息。
- 将时间状态机与 GUI 分离，使用 monotonic 时间和显式位置输入。静止等待、3 秒动画、追加后重置都可确定性测试，不依赖真实鼠标。
- 修改全局桌面状态时，恢复能力必须处于独立故障边界；单个进程的 finally 无法抵抗强制结束。
- 采用用户私有状态目录、随机令牌和 loopback IPC。启动锁、服务生命周期锁和系统状态修改锁分别处理不同并发风险。
- 自动测试覆盖逻辑与协议，桌面脚本检查真实原生尺寸和崩溃恢复；离屏截图只能证明绘制内容，不能证明置顶、穿透或跨显示器行为。
