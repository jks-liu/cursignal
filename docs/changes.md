# 关键修改

## 版本管理脚本
- 新增 `tools/version_bump.py`：提供默认 patch、minor/major、精确 X.Y.Z、--build/--no-build、只读 current，不依赖 npm 或额外 Python 库。
- 同步 pyproject.toml、运行时 __version__ 与 uv.lock 的本项目版本，保留其他依赖和文件格式；版本不一致时拒绝修改，写入失败恢复已修改文件。
- `--build` 调用 uv build 生成 wheel/sdist；构建失败保留一致的新版本并返回失败，便于直接重试构建。
- 推荐用 `uv run --no-project python` 执行，避免只读查询时先安装或同步项目。README 的 wheel 示例改为版本占位符，避免后续升版造成说明过时。
- 19 项脚本测试通过；临时副本真实升版到 0.1.1 并构建成功，wheel 元数据与运行时版本、sdist 和 `uv lock --check --offline` 均已检查。实际仓库保持 0.1.0。

## 2026-10-22
- 确定 Python/uvx 分发，使用 PySide6 Essentials 支持透明浮层和动画，避免引入完整 Qt Addons。
- 采用命令行客户端与单实例 GUI 分离，支持多个命令向同一提示追加消息。
- 将光标操作隔离为平台后端；Windows 采用原生缩放与独立恢复进程，避免 GUI 崩溃遗留放大光标。
- 实现平滑的 3 秒状态机、静止等待、多消息不同颜色追加，以及淡出期间收到新消息后重新等待。
- 实现不抢焦点、鼠标穿透、纯文本绘制、自动换行与屏幕边缘布局；超出屏幕时优先展示最近消息。
- 实现用户级启动锁、后台生命周期锁、Windows 恢复进程锁、带令牌的 loopback TCP 请求与长度限制，避免并发启动和无认证请求修改桌面。
- 增加 `--status`、`--stop`、无消息 60 秒后退出和启动错误日志；响应超时不再被当成进程不存在，以免重复启动或错误报告已停止。
- 增加 macOS 和 X11 光标图像后端，显式拒绝 Wayland；README 区分已验证平台和待验证平台。
- 增加自动测试、Windows 原生桌面验证脚本和无副作用离屏预览；修复测试发现的 Qt 延迟销毁与离屏字体问题。
- 本机已验证标准光标 32×32 → 160×160 → 32×32、动画中追加、GUI 强杀恢复和本地 uvx 安装运行；生成 wheel 与 sdist。
